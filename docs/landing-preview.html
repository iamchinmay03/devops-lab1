CI/CD Pipeline

From code push to production in minutes

11-stage automated pipeline: Jenkins, SonarQube, Trivy, Docker, Kubernetes, ArgoCD, AWS EKS.

01
⬆
Push to GitHub
Developer pushes code. GitHub webhook fires, triggering Jenkins pipeline automatically.
02
🧪
Test + Scan
Jest tests, SonarQube quality gate, and Trivy CVE vulnerability scans run in parallel.
03
🌹
Build + Push
Multi-stage Docker images built for frontend and backend, pushed to Docker Hub registry.
04
☑
Deploy via ArgoCD
ArgoCD auto-syncs to AWS EKS cluster. HPA scales pods from 2 to 10 under load.
